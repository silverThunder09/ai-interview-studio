# 하네스 문서

- 루트에는 전역 공통 원칙과 문서 안내만 둔다. 특정 경로의 구현 지침은 해당 경로 `AGENTS.md`가 소유한다.
- `workflow.md`: 위험도·실행·검증·Git·인수인계. `architecture.md`: 경계·결정·로드맵. `security.md`: 데이터 흐름·위협·라이선스·REA 도입 절차.
- `specs/`는 MVP별 요구사항·AC·검증을 소유한다. 작은 작업·PR마다 새 스펙이나 중복 보고서를 만들지 않는다.
- 승인·활성·초안 상태를 명시하고 변경·폐기된 스펙을 갱신한다. 현재 활성은 MVP 0이며 MVP 1은 초안이다.
- 문서 이동 시 규칙의 적용 범위와 링크를 확인하고 승인·보안 제약이 사라지지 않도록 한다. 상세 규칙을 루트에 다시 복제하지 않는다.
- REA 문서는 구체적 대상·권한·범위가 있는 조사 시에만 확장한다. 스킬 파일이나 doctor 결과만으로 MCP 연결을 주장하지 않는다.
