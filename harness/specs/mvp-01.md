# MVP 1 — 이력서 기반 텍스트 면접

상태: **로컬 기록과 OpenAI·Claude·Gemini 외부 API 텍스트 면접 구현 요청**. 2026-10-17 KST 사용자가 첫 단계/한도를 승인한 뒤 다음 단계 구현과 “로컬 연습·기록부터 완성”을 선택했다. 이후 사용자가 외부 API 지원을 명시적으로 요청했다. 실제 개발 중 과금·개인정보 전송은 수행하지 않고 제품 호출은 매번 사용자 선택/동의를 요구한다. 아래 연결 전 절은 공통 계약 단계의 이력이며 현재 범위는 외부 API 단계가 소유한다.

## 현재 승인된 단계와 인수 기준

- 파일 선택 → PDF 페이지/DOCX 본문 단락 추출 → 근거 위치가 붙은 읽기 전용 원문 → 사용자 수정본 → 검토 완료. 수정하면 완료 상태를 해제한다. 없는 경험이나 구조화된 경력 정보를 AI로 만들지 않는다.
- 파일 10MiB, PDF 50페이지, 총 추출 텍스트 100,000자, DOCX 선언/실제 압축 해제 30MiB, ZIP 항목 512개, XML 중첩 128단계, 추출 단락 2,000개, worker 처리 15초. 한도 초과 시 부분 성공 대신 명시적 오류다.
- native dialog에서 사용자가 선택한 한 개만 읽는다. 취소는 정상 동작, 재선택 실패는 기존 검토 내용 유지, 중복 선택 거절, 내용 비우기·화면 이탈은 진행 중 worker와 하위 worker 종료 및 메모리 상태 해제다. 원본 파일은 수정하지 않는다.
- 확장자/실제 서명·DOCX 주 문서 content type·ZIP CRC/길이·XML 형식을 확인한다. 손상·암호화·빈 문서/OCR 필요를 구분한다. PDF 빈 페이지와 읽기 순서/레이아웃의 한계, DOCX 머리글·바닥글·주석 등 미포함을 표시한다.
- PDF.js 6.4.299(Apache-2.0), fflate 0.8.3(MIT), @xmldom/xmldom 0.9.12(MIT)를 고정한다. PDF.js는 renderer bundle 전용 devDependency라 optional native canvas를 앱에 설치하지 않는다. CJK용 Adobe CMaps는 inline bundle에 포함해 외부 fetch가 필요 없고 원문 라이선스를 동봉한다.
- 파서는 sandbox renderer의 전용 Web Worker와 PDF.js 하위 worker에서 동작한다. 네트워크/문서 스크립트/링크/매크로/외부 XML entity를 실행하지 않는다. CSP는 `worker-src self`로 패키지 worker만 허용하고 `connect-src none`을 유지한다. 타임아웃은 CPU 작업을 중단하지만 OS 수준의 별도 메모리 quota는 아니다.
- 원문 bytes·추출값·수정본은 앱 메모리에서만 사용한다. 디스크·DB·로그·AI로 저장/전송하지 않으며 앱 종료/검토 화면 이탈 시 사라진다. 연습 시작을 누르기 전에는 제품 저장이 없다. 연습 기록 보존은 아래 단계의 동의를 따른다.
- 합성 문서 단위 테스트와 실제 Windows source/packaged Electron smoke로 PDF·한글 CMap·DOCX·취소·수정 상태·오류 후 보존·비우기·화면 이탈·HTML 미실행을 확인한다. 사용자 Windows에서 실제 개인 문서 정확도/파일 선택을 확인하는 수동 검증은 별도로 남긴다.

## 현재 승인된 텍스트 연습·로컬 기록

- 검토 완료 → 저장 안내/체크 동의 → 연습 시작. 추출 원문·수정본과 이후 질문/답변을 PC에 저장한다. 재검토/다른 문서는 검토 완료와 동의를 초기화한다. 저장에 동의하지 않으면 main에서도 시작 요청을 거절하며 DB에 내용을 쓰지 않는다.
- 실제 AI 대신 분리된 로컬 질문 공급자를 사용한다. 첫 질문은 단순 키워드로 프로젝트/구현 등 경험 구절 주변을 찾고 검토본에도 그대로 남아 있으면 원문으로 인용한다. 원문과 일치하지 않으면 사용자 수정본으로 구분하고, 관련 구절이 없으면 연락처를 강제로 인용하지 않는 일반 경험 질문을 제시한다. 일반 Java/Spring/DB/API/성능 질문은 이력서 근거가 있다고 표시하지 않는다. 후속 질문은 직전 사용자 답변을 그대로 인용하는 정해진 질문이다. 자동 경력 추론·AI 평가·점수는 없다.
- 기본 질문 6개와 인용형 후속 질문 6개, 총 12개 답변으로 완료한다. 답변은 빈 값/NUL을 거절하고 10,000자 이하, 저장 세션은 100개까지다. 한도 초과는 자동 삭제/잘라내기 대신 오류를 안내한다.
- main의 내장 `node:sqlite`가 `app.getPath('userData')/interviews.sqlite`에 schema v1을 만든다. 새 native npm 의존성은 없다. 시작/답변/다음 질문/완료 상태는 한 SQLite 트랜잭션으로 반영하며 동일 시작 요청·동일 답변 재시도는 중복 생성/진행하지 않는다. 내용이 다른 재시도는 거절한다.
- 화면 이동·앱 종료 후 기록에서 이어가면 정확한 미답변 질문을 복원한다. 아직 제출하지 않은 textarea 입력은 보존하지 않는다고 화면에 안내한다. 저장 실패 시 다음 질문으로 넘어가지 않고 입력을 유지한다.
- 기록 목록은 날짜·진행 상태·답변 수만 표시한다. 기록을 선택하면 질문/답변과 저장된 검토 내용을 읽을 수 있다. 삭제 대상과 복구 불가를 확인한 뒤 세션 또는 전체 기록/연결된 원문·수정본·질문·답변을 함께 삭제한다. 원본 이력서 파일은 건드리지 않는다.
- 로컬 파일은 암호화되지 않으며 위치·보존·삭제 범위를 UI에서 알린다. SQLite secure_delete 및 DELETE journal을 사용하지만 OS 백업/이전 복사본의 완전 삭제는 보장하지 않는다. 손상/미래 버전 DB는 자동 초기화하지 않고 오류를 표시한다. DB는 기록 기능 첫 요청에 열고 앱 종료 시 닫는다.
- 자동 검증: 동의/키·값·개수/외부 경로 부정 IPC, 인용 출처, 실제 SQLite 재시작/순서/중복/충돌/rollback/삭제/마이그레이션/한도. Windows source/packaged smoke는 임시 userData에서 실제 renderer→preload→main→SQLite를 실행하며 저장 오류를 주입해 입력 유지와 재시도, 12개 답변 완료, 재시작과 선택/전체 삭제를 확인한다. 사용자 실제 기록은 테스트하지 않는다.

## 목표와 범위

개인이 PDF/DOCX 이력서를 검토한 뒤 자신의 경험과 근거에 맞는 backend 텍스트 면접을 수행하고 질문·답변을 로컬에서 다시 읽을 수 있다. Java, Spring, DB, API, 성능, infrastructure, architecture, 프로젝트 경험을 다루되 이력서에 없는 경험은 단정하지 않는다. 음성·카메라·아바타·종합 점수·export는 제외한다.

## 완료된 연결 전 단계 — AI 질문 공급자 공통 계약

2026-10-17 KST 사용자가 결함 이슈가 없으면 현재 테스트를 실행하고 다음 스펙으로 진행하도록 요청했다. 다음 작업은 MVP 1의 실제 AI 질문/후속 질문이다. 이 공통 계약 단계 당시 공급자·모델·비용·전송 여부는 선택 대기였으며 이 요청만으로 유료 호출·새 외부 전송을 승인한 것으로 보지 않는다. 먼저 공급자 공통 계약을 구현·모의 검증한다.

- 현재 구현 대상: main 전용 `AIQuestionProvider`와 주입 가능한 transport, 선택한 근거/직전 답변만 담는 제한된 데이터 계약, 근거 id 검증과 원문 인용 결합, 비동기 시간 초과/취소/요청 제한/인증/연결 오류 처리.
- 공통 계약의 초기 한도: 질문 1~12, 첫 경험 질문의 명시적 선택 근거 최대 8개·구절당 180자, 후속 질문의 직전 답변 최대 2,000자, 생성 질문 1,500자·출력 600토큰·대기 최대 30초. 요청을 몰래 잘라내거나 자동 재시도하지 않는다. 공급자 연결 전에 모델·문맥/요청량·가격에 맞춰 확정한다.
- 원문 전체·파일 경로·API 키·임의 추가 필드를 요청 계약에 받지 않는다. 일반 기술 질문에는 이력서나 답변을 전달하지 않는다. 근거는 AI가 반환한 임의 문장/위치가 아니라 제공한 id를 main의 비공개 원문 snapshot에 결합한다. 수정본/원문/직전 답변을 구분하고, 문서 안 명령은 비신뢰 데이터로 전달한다. 이 검증만으로 AI 문장의 의미·사실성을 보증하지 않는다.
- 모의 AC: 잘못되거나 불필요한 입력은 transport 호출 전에 거절; 허구/추가 근거·형식 오류 응답 거절; transport의 원문 오류·인증정보 비노출; 취소/시간 초과는 abort를 무시하는 transport라도 대기를 종료하고 늦은 응답을 버림; listener/timer 해제; 한 번의 호출에 한 번의 요청만 수행.
- 현재 제품의 로컬 연습에는 연결하지 않는다. renderer/preload/IPC·SQLite schema·기존 기록 모드·CSP·장치 권한·의존성 변경이 없고 실제 AI/네트워크/키 저장/비용도 활성화하지 않는다. 공통 계약은 실제 AI 기능 완료로 표시하지 않는다.
- 공급자 선택 후 구현할 AC: 정확한 전송 미리보기와 동의, 선택한 provider/model 및 요청량/비용 안내, main 경계의 자격증명 수명주기, 질문 생성 대기/취소/재시도 UI, 외부 대기 중 DB transaction을 열지 않는 저장 흐름, 세션의 공급자/모드 복원, provider별 부정 테스트와 Windows 통합 검증. 사용자의 선택 전에는 이 경계에 의존하는 구현·호출을 진행하지 않는다.

## 외부 API 단계 — 현재 구현 인수 기준

- 공급자: OpenAI·Anthropic Claude·Google Gemini만 선택 가능. 로컬 모델·임의 호환 endpoint·SDK 의존성은 추가하지 않는다. 모델 ID는 사용자가 서비스 콘솔에서 확인해 입력하며 호환성·접근 권한이 없는 모델은 정형 오류로 멈춘다.
- 키: 비밀번호 입력을 main으로 일회 전달 후 입력을 비움. main 메모리에서만 보관하고 등록 여부만 조회 가능. 종료/창 닫기/명시적 비우기 때 해제, 재시작 후 재입력. 등록은 네트워크 호출/실제 인증 검증이 아니다. 디스크 보존은 제외.
- 시작 AC: 모델·키 등록·수정본에 포함된 구절 1개(180자)·정확한 수신 endpoint/전송 데이터/비용/서비스 보존 고지·첫 전송 동의·별도 평문 로컬 저장 동의. 불충족 시 main과 UI 모두 거절하며 로컬 연습으로 조용히 대체하지 않는다.
- 답변 AC: 세션의 공급자·모델 고정, 매번 전송 범위/비용 확인. AI 답변은 2,000자 이하. 첫 경험 질문에는 선택 구절만, 짝수 후속 질문에는 직전 답변만, 홀수 일반 기술 질문에는 개인 문맥 없이 생성 지시·질문 번호만 보낸다. 12번 마지막 답변은 외부 호출 없이 저장한다. 원문 전체/이전 대화는 전송하지 않는다.
- 실패 AC: 자동 재시도/공급자 전환 없음. 429·인증·네트워크·잘못된 JSON/근거·부분 출력은 정형 오류, 입력·기존 질문·답변 위치 보존. 취소/30초/키 변경/화면 이탈/종료는 abort하고 늦은 응답을 무시한다. 외부 대기 중 DB transaction 없음. 동일 성공 요청 재제출은 추가 호출/중복 저장 없음.
- 한도: 출력 600토큰·응답 64KiB·30초·세션 12문항·실행당 36요청(실패/취소/수동 재시도 포함). 키 재등록은 예산을 초기화하지 않는다. 앱 재시작은 초기화되며 금액 상한 보장은 아니다. 서비스 콘솔에서 과금·예산/보존을 확인하도록 표시한다.
- 보존 AC: schema 1 → 2에서 기존 기록/질문/요청 hash 보존. AI 설정·선택 구절/동의·공급자/모델만 세션에 저장하고 API 키 제외. 재시작은 공급자/질문을 복원하되 키 없는 생성은 멈춘다. 로컬/AI 모드를 구분해 표시하고 삭제는 기존 cascade 정책을 따른다.
- 검증: 합성 fetch로 세 공급자의 endpoint/header/요청·응답·형식/거절/크기/오류/호출 수; 실제 SQLite 동의/문맥 최소화/복원/마이그레이션/중복/rollback; 응답 stream 중 취소와 키 수명주기. Windows source/packaged smoke는 main fetch를 테스트 프로세스에서 합성 응답으로 대체해 UI→IPC→AI 계약→SQLite와 재시작/실패 입력 보존을 검증한다. 제품의 test flag/합성 provider 선택지는 만들지 않는다. 실제 계정 인증·서비스 가용성·모델 품질/실제 요금은 미검증이다.

설계 근거: [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [Claude Messages](https://platform.claude.com/docs/en/api/messages/create), [Gemini generateContent JSON 출력](https://ai.google.dev/gemini-api/docs/generate-content/structured-output?hl=en). 2026-10-17 KST 공식 문서 기준이며 모델 목록·가격을 앱에 고정하거나 추측하지 않는다.

로컬 파일·추출·ZIP·parser 한도는 위와 같이 확정했다. 외부 API 단계의 문맥/요청량·migration·키 수명주기는 위와 같이 명시하며 실제 모델·계정/금액 예산은 사용자가 앱/서비스 콘솔에서 선택한다. source 문서 내 지시문은 prompt injection으로 취급하고 시스템 규칙이나 tool 호출 권한으로 사용하지 않는다. 전체 이력서와 연락처를 기본 전송하지 않는 최소화 정책을 검토한다.

## 검증

- 자동: 합성 PDF/DOCX 정상·손상·암호화·형식 위장·압축 폭탄 한도·한글 fixtures; 근거 누락/허구 방지; fake AI follow-up·timeout·429·취소; SQLite migration·재시작·삭제·실패; IPC 비신뢰 입력·경로·자격증명 노출 부정 테스트.
- Windows 수동: 내려받은 exe에서 파일 선택·취소·한글 추출·검토/수정·동의·텍스트 면접·네트워크 단절·재시작 기록·삭제 확인. 사용자는 로컬 개발/빌드를 하지 않는다.
- 보안: 비신뢰 문서 parser의 권한과 자원 한도, secret OS 보관, 삭제/보존, AI 전송 동의와 redaction, 로그/CI 개인정보 부재를 검토한다. parser·모델의 라이선스도 의존성 추가 전에 확인한다.
