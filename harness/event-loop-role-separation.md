# 역할 분리 설계 기록 안내

현재 기준은 [승인된 개발 자동화](event-loop.md)와 실제 main 설정이다. 과거 역할 분리 제안·검증과 승인 근거는 [보존 기록](history/event-loop-role-separation.md)을 참고한다. 이 기록만으로 구현이나 활성화를 추정하지 않는다.

## 승인 작업을 이어가는 Actions 조정자 설치안

당시 승인과 제약은 [설치안 기록](history/event-loop-role-separation.md#승인-작업을-이어가는-actions-조정자-설치안)에 보존한다.
