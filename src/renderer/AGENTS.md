# React 화면

- 한국어 UI를 기본으로 하고 미구현 기능은 예정·비활성 상태를 명확히 표시한다.
- Node·파일·SQL·외부 AI SDK·API 키에 직접 접근하지 않는다. privileged 작업은 타입이 있는 preload API만 사용한다.
- 로딩·빈 상태·실패·재시도를 구분한다. 실패를 성공처럼 표시하거나 AI 결과를 검증된 사실로 표현하지 않는다.
- 설정 보존·초기화 안내는 실제 동작과 일치시킨다. 사용자 흐름에는 필요한 설명만 넣는다.
- 키보드 focus, label/role, 대비, 최소 창 크기와 라이트·다크·시스템 테마를 고려한다.
- 미승인 문서 업로드·마이크·카메라·외부 전송을 추가하지 않는다. 제3자 이미지·음성·폰트는 사용권 확인 없이 넣지 않는다.
- 변경한 동작은 적절한 UI/Electron 검증으로 확인한다. 문구·스타일만 바꿀 때 구현을 그대로 복제하는 테스트를 만들지 않는다.
